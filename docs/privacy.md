# 本地数据与隐私

服务通过本地 stdio 运行，默认把计划、问题、请求记录和历史保存在源码目录 `state/execution-panel.sqlite3`，可用 `--state-dir` 改位置。

为核对任务身份和读取受支持的结构化运行状态，会读取 `CODEX_HOME` 下的 `sessions/` 和 `archived_sessions/`，默认是用户主目录的 `.codex`。枚举任务时可能读取该目录下多份日志的元数据；不是只打开当前会话一个文件。读取有边界检查，不修改原始日志。`--codex-home` 可以指定隔离目录。

计划标题、节点说明、验收要求、事项和完成依据会通过 MCP 提供给客户端并显示在面板。点击 @ 后，相应上下文会进入客户端当前聊天草稿；是否发送由用户决定，后续处理遵循客户端的数据策略。

项目没有内置遥测、外部分析脚本、远程字体或 API Key。明确启动 `preview` / `scripts/demo.py` 时，HTTP 仅监听 `127.0.0.1`；这仍是可被本机进程访问的端口，不要把真实任务预览暴露到公网。

v0.5.3 生命周期 hooks 最多读取用户级 `AGENTS.md` 的 256 KiB，仅提取允许的 `auto` / `ask` / `manual` 值，并生成固定执行提醒，不把文件中的任意文字或用户提示词插入 hook 上下文。配置脚本仅在明确选择后更新同一文件中的偏好块，保留其他规则，并把旧文件备份到被忽略的 `work/config-backups/`；不会写入 hook 信任哈希。hooks 的执行与信任受宿主管理，不能保证每种客户端都会运行这些事件。

发布与反馈时不要附带：`state/`、数据库、完整聊天日志、Codex 配置、配置备份、凭据、包含私人对话的完整客户端截图。项目的 `.gitignore` 已排除常见运行目录，但不能代替提交前检查。
