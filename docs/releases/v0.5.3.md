# Codex Beacon v0.5.3 · Beacon 执行面板

原 Codex Execution Panel 更名为 **Codex Beacon**，项目地址为 <https://github.com/liuzhengxiang666/codex-beacon>。让 Agent 的执行过程看得见，也插得上手。

## 本次更新

- 统一中英文 README、展示名、UI 标题与公开链接；显示名称为 Beacon 执行面板。
- 首次配置可选 `auto` / `ask` / `manual`，复用现有用户级 AGENTS.md，保留已有选择并备份修改。
- SessionStart、UserPromptSubmit、PreToolUse hooks 提醒 Agent 根据实际多步工作判断展示，不要求先输入 @ 或调用 update_plan。
- hook 通过 Python 读取 PLUGIN_ROOT，避免 shell 环境变量语法不同或安装路径含空格、中文时定位失败。
- 移除面板底部操作提示，保留单列节点、状态、主题同步和 @ 草稿入口。

## 升级兼容

现有目录不必移动。MCP 名称 `execution-panel`、marketplace `codex-execution-panel`、技能 ID、资源 URI 和 SQLite 状态均保持兼容，不新增服务或迁移任务数据。更新命令见[安装说明](https://github.com/liuzhengxiang666/codex-beacon/blob/v0.5.3/docs/installation.md)。新 hooks 定义需要在 CLI `/hooks` 重新审核信任；安装不会绕过审核。

## 验证与边界

本地通过 91 项 Python、29 项 Node 检查；覆盖协议/历史兼容、状态、草稿、偏好保存和实际 hook 命令执行。深色 420px 与浅色 360px 无横向溢出。安装验证和远端 CI 记录见[验证说明](https://github.com/liuzhengxiang666/codex-beacon/blob/v0.5.3/docs/validation.md)。

hooks 只提供执行上下文，不能强制挂载宿主 UI。**无 @ 新任务必定自动在右侧出现，仍未完成 v0.5.3 原生端到端验收。** 不承诺所有客户端自动展开；复制成功不能替代原生草稿验收。原生 Goal 仍负责自身生命周期，面板不创建或控制第二个 Goal。
