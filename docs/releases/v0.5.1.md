# Codex Execution Panel v0.5.1 · First public preview

**让 Codex 的执行过程，看得见，也插得上手。**

An open-source MCP sidebar for Codex: track plan progress, surface blockers, and bring any step into the current chat draft with @.

## Highlights

- 编号 Plan 节点、总体完成比例与依赖感知的并行提示。
- 卡点、决定、分支及中性待验收分别展示，保留完成保护和版本历史。
- 所有节点均可 @，不必先有问题；支持原生宿主时仅追加当前草稿，不自动发送。
- 客户端主题跟随、单列岛屿布局与减少动态效果支持。
- Python 标准库 + 原生前端，无安装运行依赖；附完整本地测试、隔离演示和贡献入口。

## Install & contribute

Follow [installation](https://github.com/liuzhengxiang666/codex-execution-panel/blob/v0.5.1/docs/installation.md). Register the local MCP once, then install the skill entry from the repo marketplace. Keep the checkout path stable.

欢迎 [Issues](https://github.com/liuzhengxiang666/codex-execution-panel/issues) 和 [贡献](https://github.com/liuzhengxiang666/codex-execution-panel/blob/v0.5.1/CONTRIBUTING.md)，特别是不同客户端的可复现兼容性报告和英文 UI。

## Preview limits

Windows 桌面原生体验已实测；进度依赖 Agent 上报。@ 和右栏展开依赖宿主能力，其他平台的原生 UI 尚待验收。它不接管原生 Goal 生命周期。当前界面主要是中文。

Local validation: **80 Python + 29 Node tests passed**, plus isolated installation smoke and actual native draft-import acceptance. See [validation scope](https://github.com/liuzhengxiang666/codex-execution-panel/blob/v0.5.1/docs/validation.md).
